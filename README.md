# SistemaHotelero
Sistema básico de gestión de huéspedes, reservas y habitaciones para un hotel pequeño, desarrollado en Java, aplicando los principios de la programación orientada a objetos (POO).

La lógica y las funcionalidades del sistema fueron desarrolladas en Java en Visual Studio Code por nuestra autoria. 
Sin embargo, para el apartado grafico de la página se utilizó inteligencia artificial mediante HTML, CSS y Java Script,
